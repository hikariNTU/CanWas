CanWas

An infinite board for images and the text inside them.

CanWas is a free web application for collecting screenshots and photos on an unbounded canvas. Images may be pasted, dropped, or taken with the device camera; they may be moved and arranged freely; and the text printed inside each one becomes selectable and copyable, as though it were text on a page. The application runs entirely within the browser. No account is required to use it.

Open CanWas  ·  Source code on GitHub

1. What it does

  • Collects images on one surface. Screenshots, photos and image files are placed on a canvas that has no edges, and are positioned by dragging. The board is saved continuously as it is edited.
  • Reads the text inside them. Optical character recognition runs automatically on every image, in the browser itself, using open-source models downloaded on first use. Recognised text may then be selected with the cursor or a finger and copied. Both English and Chinese are recognised. No image is ever uploaded to a recognition service; nothing leaves the device for this purpose.
  • Works offline and installs. After its first successful load the application opens without a network connection, and it may be installed to a home screen or desktop like a native application.
  • Synchronises across devices, optionally. Connecting a Google Drive account copies boards between the user's own devices. This is entirely optional, and is described in full below.

2. What the Google account is used for

CanWas has no server and no database of its own. There is nowhere for the developer to store a user's boards, and so the only way to carry a board from one device to another is to place it in storage the user already owns. Google Drive is offered for that purpose. Signing in is optional; every feature except cross-device synchronisation works without it.

When Google Drive is connected, CanWas requests one scope:

https://www.googleapis.com/auth/drive.file Permits the application to create files in Google Drive, and to read and modify only those files it has itself created. CanWas uses it to write one file per board, into a folder it creates for that purpose, and to read those files back on another device.

This scope grants no access to any other file in the account. Documents, photographs, spreadsheets and folders that CanWas did not create are not visible to it and cannot be read, altered or deleted by it. The scope also grants no access to email, contacts, calendar, or profile information beyond the address used to sign in.

Access tokens are held in memory for the duration of a session, expire after one hour, and are not written to disk. Access may be withdrawn at any time at myaccount.google.com/permissions; boards already on the device remain there afterwards, and the files in Drive remain the user's own to keep or delete.

The privacy policy sets out precisely what is stored, where, and how to remove it.

CanWas 為免費網頁應用程式，供使用者於無邊界畫布上蒐集截圖與照片。圖片可透過貼上、拖入或裝置相機取得， 並可自由移動排列；圖片中所印之文字將可如網頁文字般選取與複製。本應用程式完全於瀏覽器端執行， 使用上無須註冊帳號。

一、功能說明

  • 於單一畫面蒐集圖片：截圖、照片與圖片檔案將置於無邊界之畫布上，以拖曳方式調整位置。白板於編輯過程中持續儲存。
  • 辨識圖片內文字：所有圖片將自動進行光學字元辨識（OCR），該作業於瀏覽器端執行， 所使用之開源模型於首次使用時下載。辨識完成之文字可以游標或手指選取並複製，支援中文與英文。 圖片不會上傳至任何辨識服務，過程中亦無任何資料離開本機裝置。
  • 可離線使用並安裝：首次成功載入後即可於無網路連線之情況下開啟， 並可如原生應用程式般安裝至主畫面或桌面。
  • 可選用之跨裝置同步：連結 Google 雲端硬碟帳號後，白板將於使用者自有之各裝置間同步。此功能純屬選用，詳如下述。

二、Google 帳號之使用目的

CanWas 並無自有伺服器與資料庫，開發者無處可儲存使用者之白板資料， 因此將白板由甲裝置攜至乙裝置之唯一方式，即為存放於使用者本已擁有之儲存空間。Google 雲端硬碟即為此用途所提供。登入為選用，除跨裝置同步外之所有功能， 未登入亦可正常使用。

連結 Google 雲端硬碟時，CanWas 僅要求下列單一權限範圍：

https://www.googleapis.com/auth/drive.file 允許本應用程式於 Google 雲端硬碟建立檔案，並僅能讀取及修改其自身所建立之檔案。 CanWas 以此為每一白板寫入一份檔案，置於其自行建立之資料夾中，並於其他裝置讀回。

此權限範圍不授予存取帳號內任何其他檔案之權利。 非由 CanWas 建立之文件、相片、試算表與資料夾，本應用程式均無法看見， 亦無法讀取、變更或刪除。該範圍亦不授予存取郵件、聯絡人、日曆之權利， 或登入所用電子郵件位址以外之個人資料。

存取權杖僅於連線期間保存於記憶體中，效期一小時，不寫入磁碟。使用者得隨時於 myaccount.google.com/permissions 撤銷授權；撤銷後已存於裝置之白板仍予保留，雲端硬碟中之檔案亦仍屬使用者所有，得自行保存或刪除。

有關儲存內容、儲存位置及刪除方式之完整說明，請參閱隱私權政策。
