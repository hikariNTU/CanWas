Privacy policy

Last updated: 20 August 2026

CanWas operates without a server. No account registration, no backend database, and no analytics integration are present. Board data is stored locally in the user's own browser. If cloud synchronization is enabled, data is additionally copied to the user's personal Google Drive. The developer of CanWas has no means of accessing or obtaining any user data.

1. Local data storage

The following data is stored on the device in use, and is retained by the browser under the origin from which this page is served:

IndexedDB canwas Board contents, including pasted or dropped images, object positions and dimensions, board names, and optical character recognition (OCR) results. OCR model weights (approximately 31 MB) are also stored here once downloaded.
Cache Storage workbox-* Copies of the application's own files — pages, scripts, styles, icons, and the typefaces they request — kept by the service worker so the application opens without a network connection. No board content is stored here.
canwas.preferredLang The preferred interface language.
canwas.drive.account Written only when Google Drive is connected. Contains the account name, email address, and profile picture URL, used to identify the account for subsequent connections. This data is not a credential and does not grant any system access.

This service does not use cookies and does not embed any third-party analytics tool, advertising tracker, tracking pixel, session recording, or error-reporting service.

2. External connections and third-party services

Other than the Google Drive synchronization feature, which is enabled only at the user's initiative, this service does not transmit board contents externally under any circumstance. When an HTTP request is made, the receiving third party obtains only the basic network information of that request, including IP address, request time, and browser user-agent string.

Google Fonts

Typefaces are retrieved from fonts.googleapis.com and fonts.gstatic.com. After the first successful load they are served from the local cache described above, so subsequent loads generally issue no request. This page loads no web font and therefore makes no such request at all.

Hugging Face

Text recognition is performed entirely on the local device. On first use, the required model weights are downloaded from huggingface.co and subsequently cached in the browser. Images are never uploaded to an external server for recognition purposes.

Google Drive (connection required)

Synchronization remains disabled until the user connects a Google Drive account. Once connected, CanWas authenticates through accounts.google.com and reads and writes files through www.googleapis.com.

  • Scope: only the https://www.googleapis.com/auth/drive.file scope is requested. This service can access only files it has created; CanWas cannot read, modify, or otherwise access any other file in the user's Drive.
  • Uploaded content: board records, images re-encoded in WebP format, and their recognized text. Files are stored in a dedicated folder within the user's personal Google Drive.
  • Security: the access token is retained only in the browser tab's memory, is never written to disk, and expires automatically after approximately one hour.
  • This service does not currently provide a feature for sharing a board across accounts.

GitHub Pages

This site is hosted by GitHub Pages. GitHub logs network requests upon each page load in accordance with its own policy; see GitHub's privacy statement. The developer has access only to aggregated, anonymized traffic statistics and not to individual logs.

3. Google API Services User Data Policy

CanWas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through Google Drive is used solely to provide the synchronization feature the user has enabled; it is never transferred to any third party, never used for advertising, and never subject to human review.

4. Data deletion and management

  • A single board: may be deleted from the board menu within the application. The board is first marked as deleted to propagate the deletion across devices, and its contents are permanently erased after 30 days.
  • Model weights: may be removed using the dedicated button in the application's About panel.
  • All local data: may be cleared directly through the browser's site data settings. This action cannot be undone.
  • Google account authorization: may be revoked at myaccount.google.com/permissions. Revocation terminates future synchronization but does not automatically delete files already written to Drive; those must be removed manually.

5. Children's privacy

This service is not directed at children and, owing to its architecture, does not collect personal information from users of any age.

6. Changes to this policy

When this policy is revised, the "Last updated" date above is updated accordingly. The full revision history is available in the project's commit history.

7. Contact

Questions regarding this policy may be submitted via GitHub Issues, the project's sole official support channel. Issue content is public; do not include any sensitive personal information.

隱私權政策

最後更新日期：2026 年 8 月 20 日

本服務（CanWas）採無伺服器架構，無須註冊帳號、無後端資料庫，亦未整合任何數據分析工具。您所建立之白板資料均儲存於個人本地瀏覽器中；若啟用雲端同步功能，系統將複製資料至您的個人 Google Drive。本服務開發者無法存取或取得您的任何資料。

一、本地資料儲存說明

下列資料均儲存於您所使用的裝置端，並由您的瀏覽器進行保管：

IndexedDB canwas 儲存白板內容（含貼入或拖載之圖片、物件位置與尺寸、白板名稱）及圖片文字辨識（OCR）結果。OCR 模型權重（約 31 MB）下載後亦儲存於此。
Cache Storage workbox-* 由 Service Worker 保存之應用程式檔案副本（含頁面、程式碼、樣式、圖示及所需字型），供無網路連線時開啟使用；其中不含任何白板內容。
canwas.preferredLang 儲存偏好介面語言。
canwas.drive.account 僅於連結 Google Drive 時寫入，包含帳號名稱、電子郵件與頭像網址，用於辨識下次連線之帳號（此資料非憑證，亦不授予任何系統權限）。

本服務不使用 Cookie，亦未嵌入任何第三方分析工具、廣告追蹤器、追蹤像素（Pixels）、操作錄影或錯誤回報服務。

二、外部連線與第三方服務

除您主動開啟之 Google Drive 同步功能外，本服務絕不傳送您的白板內容至外部。發送 HTTP 請求時，第三方服務僅會接收請求之基本網路資訊（包括 IP 位址、請求時間及瀏覽器 User-Agent 字串）。

Google Fonts

系統將自 fonts.googleapis.com 與 fonts.gstatic.com 取得字型資源。首次載入成功後即改由前述本地快取提供，其後通常不再發出請求。本頁面未載入網路字型，故完全不會發出此請求。

Hugging Face

文字辨識功能完全於本地裝置執行。首次使用時，系統須自 huggingface.co 下載模型權重，下載完成後即快取於瀏覽器中。您的圖片絕不會因辨識需求而上傳至外部伺服器。

Google Drive（僅限主動連結）

  • 權限範圍：僅要求 https://www.googleapis.com/auth/drive.file 權限，本服務僅能存取由 CanWas 建立之檔案，無法讀取、修改或存取您 Google Drive 中的其他資料。
  • 上傳內容：包含白板紀錄、重新編碼為 WebP 格式之圖片及文字辨識結果，檔案均儲存於您個人 Google Drive 的專屬資料夾中。
  • 安全機制：存取權杖（Access Token）僅保留於瀏覽器頁面分頁記憶體中，絕不寫入磁碟，並於約一小時後自動失效。
  • 本服務目前未提供跨帳號共用白板之功能。

GitHub Pages

本網站由 GitHub Pages 提供託管服務。載入頁面時，GitHub 將依其政策記錄網路請求。開發者僅能查看彙整後之匿名流量統計數據，無法存取個別日誌。

三、Google API 服務使用者資料政策

CanWas 對於自 Google API 取得資訊之使用與傳輸，均恪守 Google API Services User Data Policy，並包含「有限使用」（Limited Use）規範。透過 Google Drive 取得之資料，僅用於提供您主動開啟之同步功能，絕不轉讓予第三方、不用於商業廣告，亦不會進行人工審閱。

四、資料刪除與管理

  • 單一白板：可於應用程式白板選單中執行刪除。系統將先標記為已刪除以利多裝置同步，相關內容將於 30 天後永久清除。
  • 模型權重：可透過應用程式內「關於」面板之專用按鈕進行移除。
  • 本地端全部資料：可透過瀏覽器設定直接清除本網站之儲存資料（此操作無法復原）。
  • Google 帳號授權：可至 myaccount.google.com/permissions 撤銷授權。撤銷授權將終止後續同步功能，但不會自動刪除已存在於您 Google Drive 中的歷史檔案，如需清除須手動至雲端硬碟刪除。

五、兒童隱私保護

本服務非針對兒童設計，且因系統架構不蒐集任何個人資料，故亦不蒐集任何年齡層使用者之個人資訊。

六、政策變更說明

本隱私權政策修訂時，將同步更新頁首之「最後更新日期」。詳細修改歷程可參閱 專案檔案之變更紀錄。

七、聯絡方式

若對本隱私權政策有任何疑問，請透過 GitHub Issues 提交。此管道為本專案唯一官方支援管道；Issue 內容為公開資訊，請勿提供任何個人敏感資料。
