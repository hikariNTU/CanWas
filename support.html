Support

CanWas is an unbounded board for images. Screenshots may be pasted or dropped onto it, arranged freely, and their embedded text selected as if it were text on the page. The application runs entirely within the user's browser.

1. Obtaining assistance

GitHub Issues is the sole support channel. No support email address or live chat is provided. Reporting an issue requires a free GitHub account, and all issues are public; sensitive content, including document screenshots, must not be posted.

A report is processed more efficiently when it includes the following:

  • The action taken, the expected result, and the actual result.
  • Browser name and version, and device type (mobile or desktop).
  • The build identifier from the About panel, accessed via the i button in the corner of the application. This identifier names the exact commit in use.
  • Whether Google Drive is connected, where the issue concerns boards not matching across devices.

CanWas is a personal project provided as-is, without warranty or service-level commitment. Issues are reviewed and answered as time permits.

2. Usage

  • Add an image by pasting from the clipboard, dropping a file onto the canvas, or using the add button.
  • Navigate by dragging the empty canvas or scrolling; zoom using pinch gestures, or the scroll wheel while holding Ctrl.
  • Select text by dragging across an image once recognition has completed. Recognition begins automatically and takes a few seconds per image.
  • On a phone or tablet, a two-part control appears at the bottom of the screen. In Pan mode a finger moves the board wherever it is placed, including on top of an image, and a tap selects; in Select mode a finger moves images instead. A selected image can be deleted using the button that appears above the control. This control is not shown when a mouse is in use, where the space bar, the middle button and the Delete key serve the same purposes.
  • Install to the home screen using the browser's “Install” or “Add to Home Screen” command. The application then opens without browser chrome and, after its first successful load, without a network connection. Boards are held on the device either way; installation changes how the application starts, not where data is kept.
  • Undo with Ctrl/Cmd + Z; redo by additionally holding Shift. History is retained only within the tab and is cleared on reload; the board itself is saved continuously.

3. Troubleshooting

Text recognition does not complete on the first image

On a new device, the first image requires approximately 31 MB of model weights to be downloaded before recognition can proceed. This may take some time on a slow connection, and will fail entirely if huggingface.co is blocked on the network in use. The About panel indicates whether the weights are cached.

A notice reports that a new version is available

An updated version has been downloaded and is waiting. It is not applied automatically, because reloading during recognition discards work in progress. Select Reload when convenient, or dismiss the notice; the update will be offered again on a subsequent visit.

Text recognition does not work offline

The recognition engine and its model weights are retrieved on first use and retained thereafter. An installation that has never performed recognition while online cannot perform it offline. Boards, images and previously recognised text remain fully available.

Recognition returns incorrect characters

Text that is small, blurred, rotated, or low-contrast is recognized poorly; this is a limitation of the model rather than a configurable setting. A screenshot at its original resolution yields substantially better results than a photograph of a screen.

Boards have disappeared

Browsers may evict site storage under disk pressure, and clearing "site data," clearing "cookies and site data," or browsing in a private window will discard boards. CanWas requests storage-eviction exemption from the browser, and the About panel reports whether that request was granted. Where board persistence is important, connecting Google Drive maintains a copy elsewhere.

Connecting Google Drive has no effect

Sign-in opens a Google window; a popup blocker will prevent this. Google additionally requires that the request originate from a user click, so it cannot be retried automatically.

A board on another device did not appear

Boards are reconciled when a connection is established, not continuously. Reloading the tab re-establishes the connection and triggers reconciliation. A board deleted on one device is marked deleted and remains deleted on all devices; this behavior is intentional.

The interface appears flat or is difficult to read

The interface uses a backdrop blur effect. Browsers lacking support for it fall back to a solid panel by design. Any content that remains genuinely unreadable should be reported together with the browser name.

4. Data

Details of what is stored, what leaves the device, and how to delete it are set out in the privacy policy. In summary: boards remain in the browser, synchronization is limited to the user's own Google Drive, and no server is involved.

支援

CanWas 為無邊界圖片白板。使用者可將截圖貼上或拖入白板，自由排列， 並如同選取網頁文字一般選取圖片內之文字。本應用程式完全於使用者瀏覽器端執行。

一、取得協助

GitHub Issues 為唯一支援管道。 本服務未提供客服信箱或線上即時客服。回報問題須具備免費 GitHub 帳號，且所有 Issue 內容均為公開，請勿張貼任何私人資訊，包括文件截圖。

回報問題時，建議附上以下資訊以利處理：

  • 執行之操作、預期結果與實際結果。
  • 使用之瀏覽器名稱、版本，及裝置類型（手機或桌面）。
  • 應用程式角落 i 按鈕內「關於」面板所顯示之組建識別碼， 用以標示目前執行之確切版本。
  • 若問題涉及裝置間白板未同步，請說明是否已連結 Google 雲端硬碟。

CanWas 為個人專案，依現狀提供，不提供保固，亦無服務水準承諾。問題將依可用時間審閱並回覆。

二、操作方式

  • 新增圖片：透過剪貼簿貼上、將檔案拖入畫布，或使用新增按鈕。
  • 移動畫面：拖曳空白處或捲動以移動畫面；以雙指手勢或按住 Ctrl 鍵搭配滾輪進行縮放。
  • 選取文字：於圖片完成辨識後，直接於圖片上拖曳即可選取文字。 辨識將自動開始，每張圖片約需數秒。
  • 手機與平板：畫面下方會出現雙段式控制項。於「平移」模式下，手指無論按在何處（含圖片上方）皆為移動畫面，輕觸則為選取；切換至「選取」模式後，手指改為拖曳圖片。選取圖片後，控制項上方會出現刪除按鈕。使用滑鼠時不顯示此控制項，該情形下改以空白鍵、中鍵與 Delete 鍵操作。
  • 安裝至主畫面：可透過瀏覽器之「安裝」或「加入主畫面」功能安裝。安裝後開啟將不顯示瀏覽器介面，且於首次成功載入後即可離線使用。無論是否安裝，白板資料均保存於本機裝置；安裝僅改變開啟方式，不影響資料存放位置。
  • 復原：使用 Ctrl/Cmd + Z； 加按 Shift 鍵則為重做。操作紀錄僅保存於分頁記憶體中，重新整理後即清除；白板本身則持續儲存。

三、疑難排解

首張圖片文字辨識無法完成

於新裝置首次使用時，須先下載約 31 MB 之模型權重方能進行辨識。 於網路速度較慢之情況下所需時間較長；若使用之網路已封鎖 huggingface.co，辨識將直接失敗。「關於」面板將顯示權重是否已完成快取。

畫面提示有新版本

表示新版本已下載完成並等待套用。系統不會自動套用，因為辨識進行中重新載入將導致該作業中斷。請於方便時點選「重新載入」；若選擇稍後再說，下次開啟時會再次提示。

離線時無法進行文字辨識

辨識引擎與模型權重係於首次使用時下載並保存。若安裝後從未在連線狀態下執行過辨識，離線時即無法辨識。白板、圖片與先前已辨識之文字則不受影響，仍可正常使用。

辨識結果字元錯誤

文字尺寸過小、模糊、傾斜或對比不足時，辨識效果將明顯降低，此為模型本身之限制，非可調整之設定。 以原始解析度之截圖，其辨識效果將明顯優於螢幕翻拍照片。

白板內容消失

瀏覽器於磁碟空間不足時，可能自動清除網站儲存資料；清除「網站資料」、 「Cookie 與網站資料」，或於無痕視窗中瀏覽，均將導致白板遺失。CanWas 將主動向瀏覽器申請儲存空間豁免，「關於」面板將顯示該申請是否成功。 如白板內容具重要性，建議連結 Google 雲端硬碟以於他處保留備份。

連結 Google 雲端硬碟無反應

登入程序將開啟 Google 視窗，若彈出視窗遭封鎖將無法完成。Google 另要求此請求須由使用者點擊觸發，故無法自動重試。

其他裝置之白板未同步顯示

白板僅於連線建立時進行對帳，非持續性同步。重新整理分頁將重新建立連線並執行對帳。 於單一裝置刪除之白板將標記為已刪除，並於所有裝置維持刪除狀態，此為系統既定設計。

介面顯示扁平或難以辨識

介面採用背景模糊效果。不支援此效果之瀏覽器將顯示為不透明面板，此為預期行為。 若確有內容難以辨識，請回報並附上瀏覽器名稱。
